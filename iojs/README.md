## io.js

This container comes with `iojs`, `nvm`, and `npm` pre-installed.

### Managing versions

You can install and use different io.js versions on the container using [nvm](https://github.com/creationix/nvm).

To see which versions of io.js are installed, run: `nvm ls`

To install a different io.js version, just run: `nvm install iojs-v<version number>`.

See the [nvm usage guide](https://github.com/creationix/nvm#usage) for more
details.
