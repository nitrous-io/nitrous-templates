## io.js

This container comes with io.js, nvm, and npm already installed.

### Managing versions

You can install and use different io.js versions on the container using [nvm](https://github.com/creationix/nvm).

Presently, `iojs v1.2.0` is the default version.

To install a different io.js version, just run: `nvm install iojs-<version number>`.

See the [nvm usage guide](https://github.com/creationix/nvm#usage) for more
details.
