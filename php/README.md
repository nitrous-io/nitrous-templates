## PHP

This container comes with PHP 5.5 pre-installed.

It also includes the following software:

- Composer 1.0
- MySQL 5.5

### Composer

Composer is a tool for dependency management in PHP. It allows you to declare the dependent libraries your project needs and it will install them in your project for you. More information on usage can be found in its official [documentation](https://getcomposer.org/doc/01-basic-usage.md).
