## Golang

This container comes with Go 1.4.1 installed.

It also includes commonly used Go tools such as [goimports](https://godoc.org/golang.org/x/tools/cmd/goimports), [oracle](https://godoc.org/golang.org/x/tools/oracle), [gorename](https://godoc.org/golang.org/x/tools/cmd/gorename) and [godep](https://github.com/tools/godep).

### GOPATH

`GOPATH` is set to `~/code/go`. Hence, use `~/code/go/src/` as the base directory when creating your source repositories.
