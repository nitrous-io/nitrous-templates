### Ruby versions

This container comes with `rbenv` to help you manage Ruby versions, and has the
latest version of each Ruby minor release pre-installed:

- 2.2.1
- 2.1.5 (default)

To change the default version, run:

`rbenv global <version number>`

For more information, please consult the [rbenv README](https://github.com/sstephenson/rbenv/blob/master/README.md)

### Bundler

Bundler 1.9.4 comes installed with each Ruby version.
