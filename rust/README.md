### Rust

This container comes with `multirust` to help you manage Rust versions, and has the latest version of Rust beta and Cargo pre-installed. (Stable version of Rust is not yet available.)

To update to latest Rust beta, run:

`multirust update beta`

For more information, please consult the [multirust
README](https://github.com/brson/multirust/blob/master/README.md)
