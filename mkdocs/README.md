## MkDocs

This project comes with [MkDocs](http://www.mkdocs.org/) pre-installed. An
MkDocs project has already been generated at `~/code/example`.

You can start the MkDocs webserver by running:

```
$ cd ~/code/example
mkdocs serve --dev-addr 0.0.0.0:8000
```

Check out the [MkDocs website](http://www.mkdocs.org/) for more information on
how to use it to build documentation.
